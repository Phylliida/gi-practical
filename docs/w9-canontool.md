# w9-canontool: canonical labeling for bounded-degree graphs

`gi/canon.py` turns the bounded-degree pipeline (`gi/bounded.py`, `gi/ea2.py`) into a canonical
labeling tool. It is the canonical version of Luks's reduction (Babai–Luks 1983 §4.2–4.3, written
out in §8 of docs/canonization-bounded-degree.md), with the twin-class layer step of `gi/bounded.py`
and an F₂ linear-algebra canonizer for elementary abelian layers. Like nauty's and Traces'
canonical forms, its output is a graph certificate: a database key and a deduplication key, not
just an isomorphism test. Everything is exact and pure Python.

```python
from gi.canon import canonical_form, canonical_labeling, canon_iso
cf = canonical_form(X)                  # X: adjacency matrix; a hashable tuple
lab, aut_gens = canonical_labeling(X)   # lab[v]: label of vertex v; generators of Aut(X)
# canonical_form(X) == canonical_form(Y)  iff  X ≅ Y   (vertex colors respected)
```

`canonical_form_lists` and `canonical_labeling_lists` take neighbour lists (no O(n²) matrices).
`colors=` gives vertex colors (any sortable values); they are part of the form.
`canon_iso(X, Y)` returns `(sigma, aut_gens)` or `None`, the same value as `bounded_iso`, from the
two canonical labelings. `stats=` (a Counter) collects the `canon_*` counters. `layers="bfs"`
uses Luks's BFS layers instead of the color-class layers of `gi.bounded.class_plan`.

The form is `(n, colors by label or None, sorted codes i·n + j of the edges {i, j}, i < j)`. Two
graphs have equal forms if and only if they are isomorphic.

## 1. Design

### 1.1 Components and edge rooting

* **Components.** Each component is canonized on its own. The components are placed on
  consecutive intervals of labels, sorted by (size, form). Aut(X) is generated by the components'
  groups and one swap of each two consecutive components with equal forms.
* **Root class.** For a connected graph, CF(X) is the least rooted form CF(X, f) over the oriented
  edges f = (u₀, u₁) of a canonical class K. A rooted form sends u₀ to 0 and u₁ to 1.
  * K minimizes (size, key), first with the pair of sphere-size profiles of the two ends as key.
    Within that class, the edge invariants of `gi.bounded` (distance profiles) are the key.
  * Both keys are isomorphism invariants computed on canonical 1-WL colors (colors named by
    rank), so every isomorphism maps K onto the corresponding class.
  * On the multipedes, K has 4 edges at every size measured, out of 1536 (n = 352) to 24 576
    (n = 5632) oriented edges. On n = 2816 the cheap profile stage reaches a class of that size
    at about 1/6 of the cost of the edge invariants.
* **Trying roots.** Roots are tried one per orbit of the automorphisms found so far.
  * Rooted forms are compared by a *layered key*: per layer, the colors and the new edges. Layer
    r + 1 only adds edges at its own labels, and later steps move earlier labels only by
    automorphisms, so the key is fixed layer by layer. A root is abandoned as soon as its key
    prefix exceeds the best one.
  * Two roots with equal keys have equal forms, which gives the automorphism lab_f lab_best⁻¹.
  * Aut(X) is generated by Aut(X, f_best), these automorphisms and all others found. Every edge
    of the least orbit was either tried or skipped as the image of a tried edge with the same key.

### 1.2 The rooted form: layer by layer

* **Layers.** Each rooted graph gets rooted 1-WL colors with canonical names: a color is the rank
  of its signature among that round's signatures. The graph is then layered by
  `gi.bounded.class_plan`, which is canonical because its ties are broken by color names, or by
  BFS when the plan gives up.
* **Admissible labellings.** A labelling of the first r layers X_r is *admissible* if it sends
  the roots to 0 and 1 and each layer onto its interval of labels, and preserves the rooted
  colors. Every rooted isomorphism is admissible.
* **Invariant after layer r.** lab_r is admissible and CF_r = X_r^{lab_r} depends only on the
  rooted isomorphism type. A_r is the group of admissible automorphisms of CF_r, a group on
  labels. The admissible labellings of X_r onto CF_r are then exactly lab_r·A_r.
  With class layers, X_r alone can have automorphisms that are not admissible. At the last layer
  every rooted automorphism of X is admissible.

Step r → r + 1 (the twin-class step of `gi/bounded.py`, moved to the label side):

1. **Phase 1, up-sets.** Vertices of layer r + 1 with equal up-sets (neighbours in earlier layers)
   form twin classes.
   * Positions: the label sets lab_r(up-set) and all their A_r-images, ordered by sorted label
     tuple. This set is the same for every labelling in lab_r·A_r.
   * String x: the rank of the twin class's color multiset, or 0 where no class has that set.
   * Since x_{lab·a} = x^a, all admissible labellings give one A_r-orbit. A string canonizer
     returns F1, a₁ and U1 = Aut_{A_r}(F1).
2. **Phase 2, new labels and inner edges.**
   * New labels go to the twin classes in the order of their sets, by color within a class. The
     order within a color block is free.
   * H = ρ(U1) ⋉ ∏ Sym(color blocks) on the labels of X_{r+1}: an element u of U1 maps the
     block of a set S rank-wise onto the block of u(S).
   * The inner edges of the layer, as label pairs, form a 0/1 string on their H-orbits. Its
     canonizer gives F2 and h₀. Then lab_{r+1} = lab_r·a₁·h₀ and A_{r+1} = Aut_H(F2), or
     A_{r+1} = H when the layer has no inner edges.

**Exactness.**
* CF_{r+1} is a function of (CF_r, F1, F2). F1 and F2 depend only on orbits that are isomorphism
  invariants, so CF_{r+1} depends only on the rooted isomorphism type.
* Conversely, an admissible labelling μ onto CF_{r+1} has these properties:
  * it restricts to an element of lab_r·A_r;
  * its phase-1 string is F1, because the attachments of CF_{r+1} are F1;
  * it follows the block rule and its inner-edge string is F2.

  So μ ∈ lab_{r+1}·Aut_H(F2), and Aut_H(F2) = A_{r+1} by the same argument. These are Claims 3–5
  of §8 of the write-up, in the twin-class form.
* Every choice that shapes the output depends only on groups as sets (principle P1 of the
  write-up):
  * the position orders are fixed by the groups;
  * whether a group is elementary abelian is a property of the group;
  * both canonizers below compute least images over the whole group, not over a generating set.

### 1.3 String canonizers (`canon_group`)

* **Trivial group, or x fixed by every generator:** F = x, and the coset is the whole group.
  On CFI graphs this case covers every layer: rooted refinement plus the class plan leave nothing
  else to do.
* **Elementary abelian 2-group (`EAAction.canon`, gi/ea2.py)**, the canonical counterpart of the
  ea2 isomorphism test.
  * F is the least image of x over the group, with positions read orbit by orbit (orbits by least
    point, points increasing). The minimizers form an affine subspace c + U of F₂^k, k the rank.
  * On an orbit O the group acts regularly through G/K_O, with K_O the point stabilizer. The
    candidate translates are the classes of c + U modulo K_O, at most |O| of them, with
    representatives fully reduced against an echelon basis of K_O. They are filtered position by
    position.
  * The minimizing translates form a coset m₀ + D of the stabilizer of x restricted to O. So the
    new minimizer set is c + U intersected with m₀ + D + K_O, added as linear equations (the
    annihilator of D + K_O). Gaussian elimination on int bitmasks, with no Schreier–Sims.
  * Output: one minimizer c and a basis N of Aut_G(x). The group is abelian, so Aut_G(x) is also
    the stabilizer of F.
* **Any other group (`perm_canon`):** the least image of x along positions 0, 1, …, by a
  depth-first search over a stabilizer chain with base 0, 1, …, m − 1. Three prunings apply:
  * by value: siblings with a larger value, and prefixes above the best leaf;
  * by invariance: a node whose string is invariant under its stabilizer is a leaf and adds
    t⁻¹st as automorphisms;
  * by the automorphisms found: siblings in one orbit of the found automorphisms that fix the
    prefix are explored once, as in individualization-refinement search.

  Every least leaf is equivalent under the found automorphisms to a visited least leaf (induction
  over the pruned tree), so they generate all of Aut_P(x). This method is exponential in the
  worst case and exact always. Derived actions (on sets, on pairs) go through `ActionHom` (lift
  and kernel).

### 1.4 Where the paths are used

| family | layers | EA canonizations | permutation-search canonizations |
|---|---|---|---|
| NS multipedes `ns` | all EA or invariant | phase 1 only (5–56 per graph, n = 352–5632) | none |
| CFI over cubic graphs | all invariant | none | none |
| random regular graphs | 1 layer (rooted refinement is discrete) | none | none |
| hypercubes Q_d | BFS layers; only layer 1 has a non-invariant string | none | phase 2 (Sym(d−1)² on a matching; about 500 search nodes per root for Q8) |
| shrunken multipedes `nst`, CFI over 4-regular graphs, Heawood, Tutte–Coxeter, lifts, products | mixed | both phases | both phases |

## 2. Tests (`tests/test_canon.py`, 146 tests, about 22 s)

* **Brute force on tiny graphs.** For *every* labelled graph on n ≤ 5 vertices, the forms induce
  exactly the brute-force isomorphism classes (least adjacency string over all n! labellings), and
  |⟨aut gens⟩| equals the brute-force |Aut|. The same holds for 400 random two-colored graphs on
  n ≤ 6 vertices, and for 120 random graphs on 6–9 vertices against VF2 (pairs and |Aut|).
* **Relabeling invariance.** Many random relabelings give the same form on these graphs: random
  3-, 4- and 5-regular graphs, Q3–Q6, Petersen, the dodecahedron, grids, the torus, trees, K₃,₃,
  K₂,₅, stars, disjoint unions with repeated components, CFI graphs, and with BFS layers too.
  |Aut| is checked against known orders and against `gi.bounded`.
* **Non-isomorphic pairs.**
  * CFI twisted pairs over 3- and 4-regular bases.
  * Neuen–Schweitzer multipede pairs `ns` and `nsr` (answers from their lemma, |Aut| = 1),
    `cfix` and `nst`.
  * Random regular graphs and their non-isomorphic partners.
  * Randomly twisted CFI graphs, random graph covers (lifts) and products of small graphs,
    against `gi.bounded`'s isomorphism test on all pairs of equal size.
* **Aut generators.** Every returned generator is checked to be an automorphism (colors
  included), and |⟨gens⟩| is compared with brute force, VF2, `gi.bounded` or the known order.
* **The string canonizers** against enumeration.
  * `EAAction.canon`: random elementary abelian actions on unions of quotients of F₂^d. Checked:
    the least image in orbit-major order, and that c + span(N) is exactly the minimizer set.
  * `perm_canon`: random permutation groups of degree ≤ 7. Checked: the least image over all
    elements, and that the generators returned generate exactly the stabilizer. Also Sym(q)² on
    a matching.
* **Path coverage.** A test asserts that the permutation path is reached in both phases and the
  EA path in both phases.

Outside the suite, a one-off stress run (not committed; `test_structured_random_graphs` is its
seeded, smaller version) found no mismatch:
* 6000 random colored graphs of maximum degree ≤ 4 on 4–12 vertices, checked against VF2 on
  about 27 000 pairs, |Aut| and relabelings;
* 1200 structured graphs (lifts, products, twisted CFI), with about 780 permutation-path phase-1 and
  phase-2 canonizations, checked against `gi.bounded`.

`python3 -m pytest -q tests`: 487 passed, 19 skipped (the 341 earlier tests and these 146).

## 3. Benchmarks

**Setup.**
* **Measure.** Each mode computes the canonical forms of both graphs of a pair (X, Y) and compares
  them; the time is for the two canonical forms.
* **canon** (ours): `canonical_labeling_lists`, pure Python, wall time, in process.
* **pyn**: pynauty 2.8.8.1 `certificate`, dense nauty with default options, in a subprocess.
* **dnd / dns / dnt**: dreadnaut from nauty 2.9.1 (nixpkgs, as in docs/w1-scale.md): dense nauty,
  sparse nauty and Traces with canonical labeling on (`c`), the sum of the two reported cpu times.
* **biso** (where shown): `gi.bounded.bounded_iso_lists(X, Y)`, the isomorphism test with Aut(X),
  for reference.
* **Runs.** Benchmarks ran one after another under `nice -n 19`, with a timeout per mode and pair
  (600 s for `ns` isomorphic pairs, 120 s for `ns` twisted pairs, 200 s elsewhere), on a machine
  with 64 cores and load 3–4. Once a mode times out, its larger sizes of the same kind are skipped
  and shown as `>T` (not measured). Seed 0 throughout, so one random instance per size. Data:
  `bench/results/canon-w9-*.json`.
* **One exception to "one at a time".** During the nauty cells of the n = 1408 `ns` row, short
  single-core pytest and stress jobs ran alongside. Dense nauty's 204 s there equals the 204 s of
  docs/w1-scale.md, so no effect is visible. Our own column was measured after those jobs.
* **Clock.** Ours is Python wall time, nauty's is C cpu time at dreadnaut's 0.01 s resolution, so
  entries of 0 mean under 0.01 s.
* **Checks** on every run of ours:
  * the labelling is a bijection that maps X onto the form;
  * every generator is an automorphism;
  * |⟨gens⟩| (gi.group) equals the known |Aut|: from the NS lemma, the hypercube formula, or
    nauty's grpsize where nauty finished, else `gi.bounded`'s group;
  * the decision form(X) = form(Y) equals the known answer: from the lemma, CFI theory or the
    construction, else nauty, else `gi.bounded`.

  No answer was wrong, ours or nauty's.

### 3.4 Where we lose

The tool wins on one kind of input: bounded-degree graphs that defeat individualization-refinement.
On the rest of the benchmark it is usually behind Traces, often by two orders of magnitude.

* **Traces beats us on every family except the multipedes.**
  * Random 3-regular, n = 4000: Traces about 0.01 s per graph, ours 0.24 s (0.02 s against 0.48 s
    per pair, about 24×, and Traces is at the limit of its clock).
  * CFI, n = 3200: 0.06 s against 13.3 s per pair, about 220×.
  * Q11: 0.02 s against 4.6 s, about 230×.
  * These graphs have large automorphism groups or refine quickly, which is what Traces is built for.
* **Sparse nauty also beats us on hypercubes at every size** (Q11: 0.02 s, 230×), and on small
  instances: `cfix` up to n = 400, random graphs up to about n = 500 (level there), `nst` up to
  n = 576 (0.34 s against 1.3 s), and `ns` up to n = 1056 (level there, 0.41 s against 0.43 s).
* **Dense nauty and pynauty beat us on all hypercubes** (Q11: 0.73 s against 4.6 s) and on the
  smallest instances of the other families (CFI n = 200, `nst` up to 384).
* **Traces on `ns` below n = 1056:** 0.05 s against 0.26 s at n = 704.
* **Our CFI scaling is not yet good.** It fits n^1.8 overall, but the time grows 5.5× over the last
  doubling (2.4 s to 13.3 s). Every layer recomputes position closures over up to k = b/2 group
  generators, and this cost is shared with `gi.bounded`.
* **The bound.** There is no polynomial guarantee in general: `perm_canon` is exponential in the
  worst case (§4). It stayed small where counted (1464 search nodes over the three roots of Q8), but
  no family here was built to attack it.
* **What is not shown.** One seed per size, so instance variation is not measured here;
  docs/w1-scale.md §3.2 shows the sparse-nauty crossover on `ns` moves between n ≈ 1056 and 1760
  with σ. Traces and dense nauty may do better with invariants or other options, as only their
  defaults were run. Sizes marked `>T` after the first timeout were skipped, not measured. Miyazaki
  graphs were not run with the canonizer. Only simple undirected graphs with vertex colors are
  supported.

## 4. Relation to §8 of the write-up, and what is not claimed

* **Same reduction, different step form.** §8 uses BL83's slot encoding: every vertex is padded
  to d − 1 down-slots, Ĥ = S_q ≀ Â_r acts on slots and slot pairs, and one canonizer call is made
  per layer. Here the step is the twin-class form already used by `gi/bounded.py`: one call on
  up-set positions, then one on inner-edge pairs under ρ(U1) ⋉ ∏ Sym(blocks). The invariant,
  the reading-off of CF_{r+1} and the coset argument (Claims 1–5) carry over. The domains are
  the orbits of the sets that occur, not all slot pairs.
* **Layers.** As in the isomorphism pipeline, the layers are the color classes of a canonical
  rooted refinement in `class_plan` order, with BFS as the fallback. The invariant is stated for
  admissible labellings (§1.2), because with class layers X_r alone can have extra
  automorphisms. §8 uses BFS layers, where every rooted automorphism of X_r is admissible.
* **Canonizers.** §8 calls Theorem A, the canonical GNS recursion. Here the canonizer is a least
  image over the group: by linear algebra for elementary abelian groups (polynomial), otherwise by
  `perm_canon`'s search (exponential in the worst case). So the tool has **no polynomial
  guarantee in general**. It is polynomial on inputs whose layer groups are all elementary
  abelian or whose strings are invariant, which covers the multipedes and CFI graphs. Theorem A,
  or BL83's canonical Luks recursion for Γ_d, would be the polynomial replacement for
  `perm_canon`; it is not implemented.
* **Forms differ from nauty's.** Our form is a different (equally valid) canonical form. Equality
  of forms is the certificate, and forms are not comparable with nauty's certificates.
