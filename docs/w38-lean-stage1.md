# w38-lean-stage1: the Stage-1 degree-`d` theorem in Lean

Branch `w38-lean-stage1`. New Lean under `lean/DegreeD/` (imports the built development at
`~/math/GraphIsomorphismLog2`, which was not modified). Continues `docs/w36-lean.md`.

**Status.** All of the ask's five items are done at the abstract (`Run`) level, with the two
cited group-theory results as hypotheses (or as axioms in the `_axioms` corollary). What is proved
is the Stage-1 statement of Theorem R\* for the recursion with dispatcher (M′): runs on
`Γ̂_d` states exist (given the subroutine data, as in HJ's Stage-1 theorem) and every run with root
bounds costs `≤ exp(C' Λ log(s+2))`, `Λ = log(8 max(d,6))`, `C'` absolute. No `sorry`. Zero
axioms beyond the three standard ones in `degreeD_stage1`; `bcp` and `gnsPrimitive` in the axiom form.
HJ's own correctness (H0) is not in question here beyond what the formalization assumes.

## What is proved

### 1. `Γ̂_d` and its closure (`lean/DegreeD/GammaHat.lean`, 427 lines, new)

`GammaHat d X` (GNS Def. 2.3): `X` has a composition series with all factors embedding in
`S_d`. It is equivalent (finite groups) to `SectionsEmbed d X`: every simple quotient of every subgroup embeds in `S_d`
(`gammaHat_iff_sectionsEmbed`). Closure: `GammaHat.subgroup`, `.of_injective`, `.of_surjective`, `.range`, `.extension`, `.mono`.

The core `embeds_of_simple_quotient`: a simple quotient `T` of a permutation group on `n` points embeds in
`S_n`, by a short induction (no CFSG; a point stabilizer surjecting removes a point, otherwise `T` acts on `≤ n`
cosets of the proper image).

`q_le_of_surjective`: a group in `Γ̂_d` with a surjection onto `Alt(q)`, `q ≥ 5`, has `q ≤ d`, by orders
(`q!/2 ≤ d!`).

### 2. The dispatcher (M′) at the abstract level (`lean/DegreeD/M/Dispatch.lean`, `Run.lean`, `gen.py`)

`GI.Algorithm.Run` has the order tests in its dispatcher (`Small` for enumeration, `¬ SmallZ` for
normalization) in its constructors and it cannot express (M′), so `M.Run` is a copy with two
constructor changes:

* `Structural P Q`: `ρ(G)` in product action of `S_m ≀ S_r` on `r`-tuples of `k`-subsets of `[m]`,
  containing `Alt(m)^r`, `2k ≤ m`, `m > q₀`, `m > 4 log₂ C(m,k)` (`docs/redteam-theorem-R.md` §9(b)).
* `M.DispatchStep`: `.enumeration` with `¬ Structural`, no order test (and `ExposedSplit`, below); product unchanged.
* `Run.normalize` with `Structural` in place of `¬ SmallZ`.

The rest of the development is unchanged and regenerated by `lean/DegreeD/M/gen.py` from the
HJ sources (`Run.lean`, `Correctness.lean`, `Tree.lean`, `PhaseTree.lean`, `TotalCost.lean`, `ScriptFam.lean`,
the first part of `RealRuns.lean`; `PhaseCost.lean` generated once and then edited by hand, with
the node work `Eb` and the class). `M.Run.exact` (correctness) is proved, in every run. M.PhaseTree's `ClassOK.mult`
does not hold for enumeration anymore; this is the only change to that proof (the cost column for enumeration is `multL`).

### 3. `Q_d` and the tree (`lean/DegreeD/M/QClip.lean`, `RealRuns.lean`)

`hierQd D l = Σ log d_i · log max(min(c_i, D), 2)`, `D = max(d,6)`. Row clauses for
`phaseTreeOn_hypL` (`runKind_q`, `clipped_clauses`) in the regime `max(d,6) ≤ N^α`:

* exposure and products: `ExposedSplit.Qd_le`, `coordHier_Qd_le`. This required the exposed quotient to record
  that it splits one interval: a new Prop `ExposedSplit Q` on the dispatch and normalize constructors,
  supplied by `exists_primitiveQuotient_split` (from HJ's `exists_primitiveQuotient_of_cand`).
* cap update: `capUpdate_Qd_drop`.
* a charged child: same hierarchy, `≤`.
* rows: no row event occurs in this regime (`q ≤ d ≤ N^α` contradicts `RowCase`).

`phaseTreeOn_hypL` is restated with a general cap moment `Qf`; `real_runs_cost_le` is
Lemma 7.1 with `Qf` and weight `Λ ≥ lam d`.

### 4. `Run.VertexBound` on `Γ̂_d` states (`M/Bounds.lean`, `M/Closure.lean`)

`vclass_closed`: the class `Γ̂_D` passes to every child of a vertex of the phase tree (every
child is a forest vertex under a subgroup, `runKind_children_le`, including the aggregation
continuation cosets and script calls). `vertexBound_of_class` discharges `Run.VertexBound`:

* giant steps: `L.q ≤ max(d,6)` (`labels_q_le`).
* dispatcher counts, `DispatchStep.n_le_multL`:
  * enumeration of a non-structural `Q`: GNS 3.13: option 1 gives `|ρ(G)| ≤ d'^{c₁ log d + c₂}`; option 2 forces `m ≤ q₀` (else `Q` is
    structural), and BCP bounds the top group, `≤ (q₀!)^r (d̃+1)^{r-1}`, `d' ≥ 17^r`;
  * product refinement: the index equals `|K|`, `K ≤ S_r` a homomorphic image of `G`, `≤ d̃^{r-1}` by BCP.

### 5. The cost theorem (`M/Main.lean`, `M/PhaseCost.lean`)

Per-node hypothesis `NodeBoundD w cw af`: structural node work `≤ (N+2)^cw`, only the row terminal `≤ exp(cw log²(N+2))`,
`Solve` work `≤ (s+2)^cw`, and the script-call count bound (`calls`).
`Eb` chooses the node-work bound by regime (`D ≤ N^α`: polynomial; the row terminal cannot occur there,
`NodeBoundD.toE`). The two regimes `D ≤ N^α`, `D > N^α` use `hierQd D` and HJ's `hierQ` as cap moment
respectively (`solve_phase_bound`); in the second, `log n ≤ Λ := lam D/α`, so HJ's root
bound `Q ≤ log²s` fits `RootBoundsL`, and the row-terminal toll `exp(cw log²)` fits `exp(O(Λ log))`.
`worstCost_bound` solves the recurrence with a constant independent of `D`.

Main statements, `M.Main`:

```lean
theorem degreeD_stage1 (hP : P.Terminating) (hc : Compat P cc) (hαγ : 2 * P.α ≤ P.γ)
    (hbase : AboveBase P cc) (h4 : ∀ n, P.N₀ < n → 4 ≤ (n:ℝ) ^ ((1 - P.γ) / 2))
    (hab : ((2 * P.κ : ℕ) : ℝ) + log 9 / log 48 ≤ cc.aStar)
    {c₁ c₂} (hBCP : BCP) (hGNS : GNSPrimitive c₁ c₂) (hc₁ : 0 ≤ c₁) (hc₂ : 0 ≤ c₂)
    (hcc : c₁/log 2 + c₂/log 48 ≤ cc.a + cc.aStar/log 2)
    (hq : (log P.q₀! / log 48 + 1) / log 17 ≤ cc.a + cc.aStar/log 2)
    (hcσ : 0 ≤ cσ) (hw : NodeBoundD w cw af) (hcw : 0 ≤ cw) (haf : 0 ≤ af) (ha : af + 1 ≤ cc.a) :
    ∃ C', ∀ d {Ω C} [Finite Ω] (S : State Ω C) {A} (r : Run P .solve S none A),
      GammaHat d S.G → r.RootsOK cσ (max d 6) →
      (A = {g | g ∈ S.G ∧ ∀ v ∈ S.dom, S.y (g v) = S.x v} ∧
        (A = ∅ ∨ ∃ t ∈ S.G, A = t • autGroup S.G S.dom _ S.x)) ∧
      r.total w ≤ exp (C' * (lam d * log (S.size + 2)))
```

`M.RootsOK cσ D` is HJ's `RootsOK`: root bounds at each fresh phase, with one more clause: each
`Solve` call of a script is on a finite position set with group in `Γ̂_D`.

`degreeD_stage1_full` (`M/Final.lean`): given `Su : ∀ d, Supply P (max d 6)` and Theorem A.9's inputs, for every
`Γ̂_d` state a run of `Solve` exists, with the exact answer and root bounds, and every run with root bounds satisfies the
bound of `degreeD_stage1`. `degreeD_stage1_axioms`: the same with `bcp` and `gnsPrimitive` as axioms and the GNS constants
quantified: `∃ c₁ c₂ ≥ 0, ∀ parameters with cc.a large enough vs c₁, c₂, ...`.

## Axioms

`#print axioms GI.DegreeD.M.degreeD_stage1`: `[propext, Classical.choice, Quot.sound]`.

`#print axioms GI.DegreeD.M.degreeD_stage1_axioms`: additionally `GI.DegreeD.M.bcp`, `GI.DegreeD.M.gnsPrimitive`,
declared in `M/Axioms.lean`, with statements and justifications in `M/Cited.lean` (the repo's pattern).

* `BCP` / `bcp`: Babai–Cameron–Pálfy Lemma 2.2, as quoted by GNS Lemma 2.2: for `d ≥ 6`, a permutation group of degree `n`
  with no composition factor `A_k`, `k > d`, has order `≤ d^{n-1}`. We state it for `G ∈ Γ̂_d`, which is weaker than the source
  (a group in `Γ̂_d` has no such factor, `le_of_embedsSym_alt`; `d ≥ 6` kept).
* `GNSPrimitive` / `gnsPrimitive`: GNS Theorem 3.13. Option (2) of the theorem is stated in the product form its proof
  establishes (GNS Lemmas 3.7–3.9, types II/IV: `G ≤ P ≀ K` in product action, `P` almost simple with socle
  `A_m^{(t)}`), i.e. a bijection of `Ω` with `r`-tuples of `t`-sets, with `G` acting through `S_m ≀ S_r` and containing
  `A_m^r`, `m ≤ d`, `t ≤ m/2`, `m > 4 log₂ C(m,t)`. The docstring quotes the theorem and flags the product form as
  what the proof shows, not the literal statement; the bijection part (HJ's `ProductStructure`) is what the recursion
  consumes. `m > 4 log s` forces `m ≥ 17`, so `Aut(A_m^{(t)}) = S_m` holds.

`degreeD_stage1_full` also takes `GI.Cited.AutCardLeSq` and `GI.Cited.SimpleValuationDegree` (Theorem A.9's cited inputs),
hypotheses exactly as in HJ's `thm_main_string_stage1'`. They are not axioms of this theorem.

## Non-vacuity

* `exists_run_solve` (`M/Existence.lean`): given `Supply P D`, every `Γ̂_D` state has a run of `Solve` with the exact
  answer and root bounds (the exhaustive dispatcher, termination, the `Γ̂_D` invariant, `hierInv`, `exists_primitiveQuotient_split`). So `degreeD_stage1` is about existing runs when the
  subroutine data exist. The dispatcher (M′) is exhaustive for *every* group; only the cost analysis uses `Γ̂_d`.
* `params_exist`, `params_fit_gns` (`M/ParamsExample.lean`): for every size of GNS constants there are parameters `P, cc` (HJ's values
  with `a` large and `N₀` large) satisfying every numeric hypothesis of `degreeD_stage1`.
* `Supply P D` is HJ's `Supply` adjusted: `ContData` is built unconditionally (`contData`), `GiantCase`
  gains the requirement `cls`: an aggregation round's `Solve` calls are on groups in `Γ̂_D`. In the concrete
  aggregation these are the configuration calls on `Sym(C)`, `|C| ≤ q ≤ d`, which do satisfy it; proving it requires inspecting
  the concrete item data, which is at the Stage-2 level (`AuxQuery` in the `Aggregation` interface allows any state). This is an honest
  extra hypothesis compared with HJ's Stage-1 theorem. The row terminal's `Solve` calls are proved in `Γ̂_D`
  (`rowTerminal_calls_class`, sections of the domain group).
